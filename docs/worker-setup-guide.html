Cloudflare Workers 대시보드 접속

2

4

워커 배포

터미널에서 아래 명령어를 실행하여 워커를 배포합니다.

# worker 폴더로 이동

cd worker

# 배포

npx wrangler deploy

⚠️ 주의: 환경변수 설정 후 배포해야 합니다. Secret 변수들은 Cloudflare 대시보드에서 직접 설정하거나 wrangler secret put [변수명] 명령어를 사용합니다.

✅

설정 완료!

워커가 배포되면 폼 제출 시 자동으로:

  • 📊 Airtable에 고객 정보 저장
  • 📧 고객에게 접수 확인 이메일 발송
  • 📧 담당자에게 알림 이메일 발송
  • 📱 텔레그램 채널로 알림 전송
