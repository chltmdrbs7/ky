📊 Google Analytics 4 API 설정

KY 중소기업지원센터 대시보드 연동을 위한 설정 가이드

✅ 진행 체크리스트

1

Google Cloud 프로젝트 생성

1. Google Cloud Console에 접속합니다.

2. 상단의 프로젝트 선택 드롭다운 클릭 → "새 프로젝트" 클릭

3. 프로젝트 이름 입력:

ky-analytics

4. "만들기" 클릭

2

GA4 Data API 활성화

1. 생성한 프로젝트가 선택된 상태에서 아래 링크 클릭:

🔗 Google Analytics Data API 활성화 페이지

2. "사용" 버튼 클릭

⚠️ 프로젝트가 "ky-analytics"로 선택되어 있는지 확인하세요!

3

서비스 계정 생성

1. 아래 링크로 이동:

🔗 서비스 계정 관리 페이지

2. "+ 서비스 계정 만들기" 클릭

3. 서비스 계정 이름 입력:

ga4-reader

4. "만들고 계속하기" → "완료" 클릭

5. 생성된 서비스 계정 이메일 확인 (형식: ga4-reader@ky-analytics.iam.gserviceaccount.com)

🔑 JSON 키 다운로드:

  1. 생성된 서비스 계정 클릭
  2. "키" 탭 선택
  3. "키 추가" → "새 키 만들기"
  4. JSON 선택 → "만들기"
  5. 다운로드된 JSON 파일 안전하게 보관

🔒 보안 주의: JSON 키 파일은 절대 외부에 공유하지 마세요!

4

GA4 속성에 권한 부여

1. Google Analytics 접속

2. 좌측 하단 ⚙️ 관리 클릭

3. "속성" 열에서 "속성 액세스 관리" 클릭

4. 우측 상단 "+" → "사용자 추가"

5. 서비스 계정 이메일 입력:

6. 역할: "뷰어" 선택

7. "추가" 클릭

📝 GA4 속성 ID 확인:

관리 → 속성 설정 → 속성 ID (숫자만 복사)

5

Cloudflare Worker 환경변수 설정

1. Cloudflare Dashboard 접속

2. Workers & Pages → ky-form Worker 선택

3. Settings → Variables

4. 아래 환경변수 추가:

GA4_PROPERTY_ID

GA4 속성 ID (숫자)

GA4_CLIENT_EMAIL

서비스 계정 이메일 (JSON 파일의 client_email 값)

GA4_PRIVATE_KEY

서비스 계정 비밀키 (JSON 파일의 private_key 값, -----BEGIN...부터 전체)

💡 팁: JSON 파일을 열어 client_email과 private_key 값을 복사하세요.

6

Worker 코드 배포

환경변수 설정 완료 후, Worker를 다시 배포합니다:

cd worker

npx wrangler deploy

배포 완료 후 대시보드에서 통계가 표시되는지 확인합니다:

📊 통계 대시보드 확인

🔧 문제 해결

데이터가 표시되지 않아요
  • 서비스 계정이 GA4 속성에 추가되었는지 확인
  • GA4_PROPERTY_ID가 올바른지 확인
  • private_key에 줄바꿈(\n)이 포함되어 있는지 확인
403 Forbidden 에러
  • GA4 Data API가 활성화되었는지 확인
  • 서비스 계정에 "뷰어" 권한이 있는지 확인
인증 에러
  • GA4_CLIENT_EMAIL이 정확한지 확인
  • GA4_PRIVATE_KEY가 완전히 복사되었는지 확인 (-----BEGIN부터 -----END까지)
